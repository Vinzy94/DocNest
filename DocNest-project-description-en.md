# DocNest — Project Description

## Overview

DocNest is a Windows application that brings together everyday document tasks in one workspace: PDF management, scanning, images and office documents.

The interface is organized into independent tabs, with a visual Home screen and accessible tools designed for users who need practical document workflows without the complexity of professional publishing software.

## Main features

- Visual PDF page organization with thumbnails, drag and drop, reordering, rotation and deletion.
- PDF splitting with both the traditional workflow and two areas for moving pages by drag and drop.
- PDF merging.
- PDF signing with reusable stored graphic signatures.
- PDF compression.
- OCR for making scanned documents searchable.
- Export to PNG, JPEG and TIFF.
- PDF to Word conversion.
- Watermarks.
- Import of images, Word documents and PowerPoint presentations.
- Zoomable previews and multiple tabs for working on several documents at the same time.
- Stand-alone Windows x64 installer.
